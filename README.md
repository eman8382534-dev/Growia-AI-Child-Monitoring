# Growia - AI Child Monitoring Platform
### Graduation Project 2026

A smart platform for monitoring and improving children's behavior using Artificial Intelligence.

### Overview
Growia helps parents track their child's daily data (mood, grades, behaviors). The AI analyzes this data to identify weaknesses and suggests personalized activities for improvement.

### Tech Stack
- **Backend:** ASP.NET Core Web API
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQL Server
- **AI Module:** Behavior Analysis & Activity Recommendation System

### Project Structure
- `/Frontend` : Contains all user interfaces (Parent, Admin, Child dashboards)
- `/` (Root) : Contains Backend API files (Controllers, Models, Services)

### How to Run Locally
1. Rename `appsettings.Example.json` to `appsettings.json` and add your own database and keys.
2. Run the Backend API from Visual Studio.
3. Open Frontend files using Live Server.
